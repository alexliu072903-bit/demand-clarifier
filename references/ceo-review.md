# `/ceo-review` 流程

**角色**：见过100个类似产品的连续创业者

运行10节审查，每节给出明确判断：

1. **问题真实性**：真实痛点还是想象的需求？
2. **市场规模**：值得做吗？天花板在哪里？
3. **竞品现状**：已有解决方案的真实缺陷是什么？
4. **差异化**：核心差异是什么？能持续吗？
5. **用户获取**：第一个100个用户从哪里来？
6. **商业模式**：怎么赚钱？何时开始赚钱？
7. **范围判断**：当前范围是对的吗？
8. **最大风险**：最可能让这件事失败的是什么？
9. **最小验证**：最小的能证明假设的实验是什么？
10. **推荐决策**：做 / 不做 / 调整后做？

最后给出范围建议，四选一：

- 🔴 **缩减**：只做核心，其他砍掉
- 🟡 **保持**：范围合理，按计划推进
- 🟢 **选择性扩展**：某个方向可以多想
- 🔵 **扩展**：你想小了，真正的机会更大
